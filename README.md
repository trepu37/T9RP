# rut9 — умный РП-Т9 для Minecraft 1.21.8 (Fabric)

Контекстные подсказки серым текстом для `/me`, `/do`, `/todo`, `/try`, автоисправление раскладки и опечаток,
деепричастия в `/todo`, необязательная LLM (OpenAI-совместимый API / Ollama).

## Как получить готовый .jar (без установки чего-либо на ПК)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (вместе с `.github/`).
2. Откройте вкладку **Actions** → workflow **build** запустится сам (или нажмите *Run workflow*).
3. Через 3–6 минут откройте завершённый запуск → внизу **Artifacts → rut9-mod** → скачайте архив, внутри `rut9-2.0.0.jar`.
4. Положите jar в `.minecraft/mods/` рядом с **Fabric API** (Minecraft 1.21.8, Fabric Loader ≥ 0.16.14).

Релиз по тегу: `git tag v2.0.0 && git push --tags` — jar появится на странице **Releases**.

## Словарь
При сборке скачивается частотный список русских слов (hermitdave/FrequencyWords, CC BY-SA 4.0, ~1,4 млн форм),
в jar попадает до 400 000 самых частых слов (`-PdictLimit=...`). В игре по умолчанию загружаются первые 300 000
(`dictMaxWords` в `config/rut9/config.json`, ≈ 80 МБ ОЗУ). Миллион слов в память не помещается разумно — поэтому ограничение.
Исправление опечаток работает по первым 20 000 самым частым (`dictIndexWords`); остальные слова считаются «известными»
и не «исправляются», а участвуют в дописывании слова.
Если на этапе сборки нет сети, сборка не падает — мод просто работает на встроенном маленьком словаре
(в логе Actions будет предупреждение).

## Настройка
`config/rut9/config.json`: РП-режим (`rp*`), LLM (`llmEnabled`, `llmUrl`, `llmApiKey`, `llmModel`).
Проверка LLM: `/t9 llmtest`. Свои данные: `config/rut9/chains.json`, `rp_verbs.txt`, `rp_nouns.txt`, `rp_words.txt`,
после правок — `/t9 reload`.
Клавиши: Tab — принять, Вверх/Вниз — вариант, Alt+1..3 — выбрать, F9 — причесать строку, F8 — панель обычного чата.

## Локальная сборка (необязательно)
JDK 21 + Gradle 8.14: `gradle build` → `build/libs/rut9-2.0.0.jar`.
Версии Yarn/Fabric API в `gradle.properties` сверьте на https://fabricmc.net/develop/ (выберите 1.21.8).
